Publish to FoundryVTT, automatically

A GitHub Action that registers each new release with FoundryVTT's official Package Release API — version, manifest, and compatibility — straight from your release workflow.

Get it on GitHub

The difference

By hand, every release

  1. Open foundryvtt.com and sign in
  2. Find your package, click edit
  3. Paste the versioned manifest URL
  4. Retype the version and compatibility
  5. Submit — and repeat next time

Wired up once

  1. Tag and publish a GitHub Release
  2. The action reads your manifest
  3. It posts to the Package Release API
  4. FoundryVTT records the new version
  5. You walk away

The entire setup

Three steps to wire it up

  1. Add a FOUNDRY_TOKEN secret

    Grab a Package Release API token (it starts with fvttp_) from your package's edit page on foundryvtt.com, then add it as a repository secret named FOUNDRY_TOKEN.

  2. Add the publish step to your release workflow

    Adapt the workflow above, or drop the publish step into your existing release job. Point manifest-path at the manifest file your build produced, and manifest-url at that same file's public Release-asset URL.

  3. Publish a GitHub Release

    That's the trigger. The action validates your manifest and publishes the version to FoundryVTT automatically.
